# Open-Source Projects

## JediKG

Dataset extraction framework for neurosymbolic learning.

Features:

* Knowledge graph sampling
* Schema modularization
* Ontology reasoning
* Benchmark generation

GitHub: https://github.com/ara-t3/jedikg

## PyKEEN-NS

Schema-aware negative sampling extension for PyKEEN.

Features:

* Static negative sampling
* Dynamic negative sampling
* Reproducible experimentation
* Ontology-guided corruption strategies

GitHub: https://github.com/ara-t3/pykeen-negative-sampling

## TriQlet

Quantum metric learning framework built with PyTorch and Qiskit.

Features:

* Quantum Siamese Networks
* Modular ansatz design
* Quantum embedding layers
* Hybrid quantum-classical learning

GitHub: https://github.com/ivandiliso/triqlet
